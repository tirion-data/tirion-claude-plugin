# QC checklist for prospect research deliverables

Run this before any answer, brief, profile or packet goes to the user. Each item
has the check and the fix. A first draft usually fails at least one item. That is
normal. Fix it and run the list again.

## 1. Identity

| Check | Fix when it fails |
|---|---|
| At least two independent anchors (middle name or initial, city, employer, spouse, age range, degree, board seat) tie the subject to every section. | Remove any fact you cannot tie to an anchor, or mark it "unconfirmed: may refer to a namesake". |
| Namesakes were looked for (same name, same state or same field). | Run a name search with and without the state. List the other candidates and the fact that separates each one. |
| The profile's facts fit one life: one career path, compatible ages, plausible places. | If they do not, flag a possible mix of namesakes. Keep only anchored facts. |
| Family links rest on a record: a shared deed, a joint gift credit, a proxy or obituary that names the relative. | Remove links based only on a shared surname or a shared city. |
| Each person in a couple or family is identified separately. | Split the facts by person. Say which facts belong to whom. |

## 2. Sourcing

| Check | Fix when it fails |
|---|---|
| Every material fact names its record and date: "SEC Form 4, filed 2026-08-24", "Palm Beach County Property Appraiser, 2026 roll", "IRS Form 990-PF, FY2023, Part XIV", "FEC, 2024 cycle". | Add the record and date, or drop the fact. |
| URLs are included where a tool or search returned one. | Add them to the Sources list. |
| Inferences are labeled as inferences and state their basis. | Rewrite as "Inferred from (fact): ..." |
| News facts come from articles that show the subject (same employer, role or city). | Drop articles that only match the name. |
| Conflicts between sources are shown, not silently resolved. | State both values and which source is more recent or more direct. |
| Prefer primary records (government filings, the organization's own report) over press, and press over vendor scores. | Replace a secondary source with the primary one where you can find it. |

## 3. Capacity reasoning

| Check | Fix when it fails |
|---|---|
| Capacity is a range, with the rating label where one exists, its drivers, exclusions and confidence. | Rewrite in the capacity-research output format. |
| Assessed property value is not called market value. | Say "assessed" and, where relevant, how the county's assessment relates to market (for example, California's Proposition 13 keeps long-held assessments below market). |
| Stock awards, options and unvested shares are not called cash. | Separate vested and sold from granted and unvested. |
| Gross sale proceeds are not called net worth. | Call them proceeds, dated, before tax. |
| Foundation assets are not called personal wealth. | Call them foundation assets and use them as evidence of inclination and a floor on family wealth. |
| Capacity is kept separate from inclination and affinity. | State capacity first, then say how inclination and affinity shape the ask. |
| Visible assets are treated as a floor, with a note on what may sit above them. | Add the upside and its basis (private company, partnership, trust). |
| Assets are counted once. A Form 4 holding and the same shares in the proxy ownership table are one asset. | Deduplicate. |
| Only assets the person controls drive the rating. Spouse, parent or family-trust assets are noted as upside. | Move them to the upside line. |

## 4. Recency

| Check | Fix when it fails |
|---|---|
| Every figure has an as-of date. | Add it. |
| Holdings reported by someone who has left the company or board are marked "last reported (date); current holding not confirmed". | Add the caveat. |
| Titles and board seats were confirmed within the last year, or dated. | Recheck the organization's site or latest filing. |
| 990 data is identified by fiscal year. It usually trails by one to two years. | Add the fiscal year. |
| Recent events (last 12 to 24 months) were checked: Form 4 sales, company deals, property sales, new roles, honors. | Run the check before delivery. |

## 5. Ethics

| Check | Fix when it fails |
|---|---|
| Only public and properly sourced information is used. | Remove anything else. |
| No personal cell, personal email, or home phone. | Remove. A business address or the organization's main line is fine where relevant. |
| No health, religion by inference, sexual orientation, immigration status, or facts about minors. | Remove. A child may be named only as an adult with a public role relevant to the relationship. |
| Nothing came from pretexting, logged-in pages, or data brokers of unclear origin. | Remove and note the gap instead. |
| Everything included is relevant to cultivation, solicitation or stewardship. | Cut facts that are merely interesting. |
| You would be comfortable if the prospect read the document. | If not, remove the fact or rewrite it neutrally. |

## 6. Deliverable form

| Check | Fix when it fails |
|---|---|
| Title, date, "Prepared by ... with AI assistance", "Reviewed by" (a named person), and what the document is for, at the top. | Add them. If no person has reviewed it, mark it "draft, not yet reviewed". |
| Facts from the organization's own records (giving, pledges, contact history, officer rating, self-reported statements) are attributed to the officer who supplied them, and none were invented. | Attribute or remove. Leave a marked placeholder for what the user did not provide. |
| Research capacity, the organization's rating and the officer's expected next gift are shown separately with their horizons. | Split them. Never merge or average them. |
| One-paragraph summary at the top that leads with the conclusion. | Move the conclusion up. |
| A recommended next step. | Add one: who, what, by when. |
| Gaps are listed with what would close each one. | Add a "What we do not know" section. |
| Numbered Sources list at the end: record, date, URL. | Add it. |
| No Tirion internals: no IDs, field names, rating codes other than the capacity label, or notes about what the database holds. | Rewrite in terms of the person and the public record. |
