# Public statistics for area wealth

Cite every statistic with its table, geography and vintage.

| Question | Source | Detail | Lag / vintage |
|---|---|---|---|
| How many high-income households in a ZIP | IRS Statistics of Income (SOI), "Individual Income Tax Statistics: ZIP Code Data" (irs.gov/statistics) | Number of returns by AGI size class; the top class is $200,000 and over | About 2 to 3 years behind the current year |
| Investment income in a ZIP | Same | Returns with dividends, interest, net capital gain, and their amounts | Same |
| Charitable giving in a ZIP | Same | Returns with itemized charitable contributions and the amount. Itemizing fell after the 2017 tax law raised the standard deduction, so compare years with care | Same |
| Median household income | Census ACS 5-year estimates (data.census.gov), table B19013 | County, tract, ZIP Code Tabulation Area (ZCTA) | 5-year window; name it (for example 2019-2023) |
| Household income distribution | ACS table B19001 | Top bracket is $200,000 or more | Same |
| Median home value | ACS table B25077 | Owner-occupied units | Same; self-reported value |
| Educational attainment | ACS table B15003 (or S1501 subject table) | Graduate and professional degrees | Same |
| Top industries | Census County Business Patterns | Establishments, employment and payroll by NAICS industry | About 2 years behind |
| Top employers | State labour department or workforce agency; county economic-development office | Named employers, often by employee band | Varies; cite the date |
| Home sale prices | County recorder; the state's sales disclosure where it exists | Recorded sale prices (not recorded in some non-disclosure states) | Near current |
| Assessed values | County assessor or property appraiser roll | Assessment ratios differ by jurisdiction | Annual roll; cite the roll year |
| Foundations | IRS Business Master File and 990-PF filings; ProPublica Nonprofit Explorer; Candid (licensed) | Assets, grants, trustees | 990s run 1 to 2 years behind |

## Notes

- A ZCTA approximates a ZIP code; it is not identical. Say "ZIP Code Tabulation Area" when you use ACS.
- IRS SOI suppresses small cells for privacy. A missing value is suppressed, not zero.
- ACS estimates carry margins of error. For small tracts they are wide. Quote the margin when the comparison depends on it.
- Assessed-value deciles from Tirion describe property assessments, not household wealth. Pair them with IRS or ACS income figures to describe a place.
